# Paralax FX

The shop for Paralax FX sci-fi HUD kits for DaVinci Resolve. Lives at fx.paralaxverse.com.

- Edit text in the .html files, styles in css/site.css.
- Paste Lemon Squeezy checkout links into the CHECKOUT list at the top of js/site.js to switch the buy buttons on.
- Pushing to the main branch updates the live site through Cloudflare.
